The transferable work is numerical software and verification. A correct result inside this rule model does not establish a model for financial risk or another real-world decision.

What this shows

These saved examples use six decks, a dealer who stands on soft 17, a completed peek without blackjack and no surrender. Values are expected net return per original wager, not win probabilities. Both hands have negative expected return. Split valuation elsewhere in the project is approximate.
