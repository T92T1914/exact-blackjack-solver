Record versions, export and representation limits

Schemas 1 and 2 retain the original/default independent-hand and greedy shared-budget split approximation, with no general error bound. Schema 3 explicitly declares a bounded common-shoe model for two split hands. Schema 4 declares bounded post-peek late surrender for one original initial hand, with supplied depleted counts and current permission. Schema 5 declares a bounded common-shoe resplit model for an original non-ace pair, up to three hands and one shared extra slot. Schema 6 separately declares an original A,A with one shared optional extra ace resplit, at most three hands and one mandatory card per split child. Schema 7 declares an original unsplit hand with the dealer second card deferred until player completion, no peek, and loss of every committed wager to dealer natural. Schema 7 is an original-hand S/H/D family, not a split model.

bj-advise T,4 T --unseen 2,3,7,8,9,T --json

Add --no-double or --no-split to exclude that current choice without changing continuation rules. Defaults keep version 1 records; a disabled choice produces version 2 with stored controls. The viewer distinguishes these declarations from implicit defaults.

Save the command's JSON output as a UTF-8 file using your shell or editor. The viewer accepts schema versions 1, 2, 3, 4, 5, 6 and 7, at most 65,536 UTF-8 bytes, container depth eight and integer tokens up to 4,300 decimal digits. Those are browser representation limits, not engine work or memory limits. Integer counts remain exact. Raw answer numbers are interpreted as finite binary floats without display rounding.

What this shows

These saved examples use six decks, a dealer who stands on soft 17, a completed peek without blackjack and no surrender. Values are expected net return per original wager, not win probabilities. Both hands have negative expected return. The original/default split path is approximate. The separately selected bounded common-shoe families enumerate their admitted joint continuations in binary floating point.
