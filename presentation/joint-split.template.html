What the comparison holds fixed

Each unseen shoe contains eight cards and includes a reserved hidden dealer hole. Visible pair cards and the dealer upcard are already excluded. The balanced shoe has two each of 7, 8, 9 and T. The ten rich shoe has one 7, one 8, two 9s and four tens. Both are high rank toy compositions, not a sample of ordinary shoe frequencies.

The protocol crosses those shoes with pairs 2, 5, 8 and A, dealer upcards 6, T and A, and both states of double after split, abbreviated DAS. The dealer stands on soft 17. There are exactly two hands, no resplits and no surrender. Split aces get one additional card each.

The first hand finishes before the second receives its additional card. Choices maximize the combined round value using only visible information and the completed peek. The hidden hole is averaged before choosing an action. Both final hands settle against one shared dealer outcome.

A missing draw in any admitted action, including an action that might later be rejected, makes the condition unsupported. Limits are 100,000 reference states, ten reference seconds and twenty wall seconds per condition. The runner preserves failures instead of replacing them with a value. A recommendation changed into a tie

For a pair of fives against a six in the balanced shoe with DAS allowed, production preferred double with a margin of 0.023809524. Replacing only the split value made double and split tie within 1e-12, with a raw numerical margin of zero. The original double recommendation remained in the best set. No condition changed to a disjoint best action set.

The root comparison preserves production stand, hit and double values. S means stand, H hit, D double and P split. Each value is expected net return per original bet. A doubled split hand risks two units. Margins are the best value minus the next value, not win probabilities.

The first comparison was invalid

The first runner passed a count array in reference rank order to production, whose rank order starts with A. It therefore compared different card compositions. Its gaps and combined root recommendations are invalid for the declared question. The raw attempt remains available, clearly separated from the matched result above.

The correction maps counts by rank name and records both schemas in every completed row. An asymmetric mapping regression was added before the corrected attempt. The protocol, reference arithmetic and production model did not change. The corrected 48 condition attempt ran once, and the report independently checks rank identities and recomputes gaps, rankings and margins from its retained values.

Read the limits with the result

The reference has its own hand, draw and dealer arithmetic. Tiny independent tests enumerate physical card permutations with rational values, check hidden information, and reject unsupported exhaustion. The 48 condition study is broader than those fixtures but remains a constructed high rank family. It does not establish full shoe accuracy, resplitting behavior or an advantage in real play.

The older lower and upper resplit bracket concerns shared slot allocation inside the independent hand model. It does not bound the shared shoe effects measured here. The existing studies and production defaults remain intact.
